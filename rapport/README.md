# مذكّرة التخرّج — البحث النفسي (LaTeX)

**العنوان:** إدراك أسلوب المعاملة الوالدية المتسلطة وعلاقته بتقدير الذات لدى المراهقين — دراسة نوعية (15–16 سنة).

الملف الرئيسي: `rapport.tex`

## كيف تُترجم الملفّ إلى PDF؟

### الطريقة الأسهل: Overleaf (مستحسَنة — تدعم العربية والخطوط جاهزة)
1. ادخل إلى https://www.overleaf.com وأنشئ مشروعاً جديداً (New Project → Blank Project).
2. ارفع ملفّ `rapport.tex`.
3. من القائمة **Menu → Settings → Compiler** اختر **XeLaTeX**.
4. اضغط **Recompile**. سيظهر التقرير كاملاً مع الفهرس والمخطّطات.

> الخطّ المستعمل هو **Amiri** وهو متوفّر تلقائياً على Overleaf.

### على الحاسوب (TeX Live / MiKTeX)
يلزم محرّك **XeLaTeX** وخطّ **Amiri** مثبّتاً على النظام، ثمّ:

```bash
xelatex rapport.tex
xelatex rapport.tex   # مرّتان حتى يُبنى الفهرس وفهرس الجداول/الأشكال
```

## ماذا يحتوي التقرير؟
- صفحة غلاف + شكر + ملخّص + **فهرس المحتويات** و**فهرس الجداول** و**فهرس الأشكال** (تلقائية).
- مقدّمة، ثمّ 4 فصول: الإطار النظري (مفهومان)، الإطار المنهجي، عرض/تحليل/مناقشة النتائج.
- **المراجع مُدرَجة داخل المتن** بنمط APA `(Baumrind, 1966)` … إلخ، وقائمة مراجع كاملة في الآخر.
- **4 مخطّطات بيانية** مرسومة داخل LaTeX (لا تحتاج صوراً خارجية):
  1. توزيع العيّنة حسب الجنس.
  2. توزيع العيّنة حسب السنّ.
  3. نِسب المؤشّرات (نتائج تحليل المضمون).
  4. درجات تقدير الذات لكلّ مشارك مع خطّ المتوسّط.
- جداول: وصف العيّنة، شبكة تحليل المضمون (9 مشاركين × المؤشّرات)، درجات التقدير الذاتي.
- **الملاحق:** التفريغ الحرفي لإجابات المشاركين التسعة (1–22).

## أماكن تحتاج تعديلها قبل التسليم
- صفحة الغلاف: اسم الجامعة/الكلية، اسم الطالب(ة)، اسم المشرف(ة).
- إجابات المشاركين في الملحق (01) **افتراضية** صُمّمت لتطابق النِّسب المعتمدة؛ استبدليها بإجابات
  حقيقية إن أُجريت مقابلات فعلية.
- تحقّقي من تفاصيل المراجع (الصفحات/السنوات) قبل التسليم.
